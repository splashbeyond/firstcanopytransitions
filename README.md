# First Canopy Transitions

Standalone owner-facing website for First Canopy Transitions.

## Local preview

```bash
npm run dev
```

The site runs at `http://localhost:4173` by default. Set `PORT` to use another port.

## Before launch

- Connect `firstcanopytransitions.com` and redirect the apex domain to `www.firstcanopytransitions.com`.
- Verify the canonical URL and submit `sitemap.xml` in Google Search Console after launch.
- Confirm the Calendly event URL and owner-facing booking questions.
- Have legal counsel approve the owner-facing disclosures and compensation language.
- Connect form analytics only after the privacy policy and consent approach are approved.
